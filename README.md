## 🚀 Selected Projects

### [🎥 Facial Emotion-Based Movie Recommender](https://github.com/thecritiz/distraction-detect)  
Real-time facial emotion detection using OpenCV and CNNs to recommend content dynamically.  
Built with React, FastAPI, OpenCV, TensorFlow.

### [👁️ Attentiveness Checker](https://github.com/thecritiz/attentiveness-checker)  
Facial landmark tracking with MediaPipe and OpenCV to evaluate human attention in real-time.

### [🏠 Real Estate Web App](https://github.com/thecritiz/real-estate-app)  
Full-stack JWT-authenticated property listing platform with filters, animations, and dashboard.

### [🦶 Gait Recognition – LidarGait++](https://github.com/thecritiz/lidargait-sustech1k)  
Research implementation of Point Transformer Blocks on SUSTech1K gait dataset for biometric ID.
